# Тактический авто-баттлер (рабочее название)

Игрок расставляет героев с отрядами по сетке и запускает бой, в который не может
вмешаться. Весь геймплей — в подготовке.

## Состояние

**Фаза 0 — скоуп-контракт.** Работающий каркас + детерминированное ядро в зачатке.
Реестр задач: `docs/TASKS.md`. Открытые вопросы: `docs/QUESTIONS.md`.

## Быстрый старт

```bash
pnpm install
pnpm test        # 19 тестов, включая эталонные векторы PCG32
pnpm bench       # гейт P0-07 — см. docs/BENCH_P0-07.md
pnpm typecheck
```

## Структура

| Пакет | Назначение | Зависимости |
|---|---|---|
| `packages/sim` | ядро симуляции | **ноль, включая браузерные и Node API** |
| `packages/data` | контент и Zod-схемы | sim |
| `packages/render` | PixiJS v8 | sim, data |
| `packages/meta` | прогрессия, сейв | sim, data |
| `packages/app` | оболочка, экраны | все |
| `packages/tools` | генераторы таблиц, бенчи, баланс | sim, data |

## Инварианты детерминизма

В `packages/sim` **запрещено**: float в игровой логике (только Fixed Q16.16),
`Math.random` (только seeded PCG32), `Date.now`/`performance.now`,
`Math.sin/cos/sqrt/pow` (только предвычисленные таблицы), async/промисы/таймеры,
порядок из `Object.keys`/`Set`/`Map`, любые внешние API.

**Обязательно**: фиксированный тик 1/30 с; обход сущностей по возрастанию `entityId`;
один RNG-поток с фиксированным порядком потребления; спавн и смерти — пакетом в конце тика.

Нарушение = критический баг. Любое изменение в `sim` проходит `determinism.test.ts`
и golden-реплеи.

## Что уже работает

- `fixed.ts` — Q16.16 через hi/lo split на `Math.imul`, плюс домен Q24.8 для мировых координат
- `rng.ts` — PCG32 XSH-RR, **совпадает с эталонными тест-векторами** референсной C-реализации,
  4 независимых потока, сериализация состояния
- `trig.ts` — BAM-углы (полный оборот = 2³², модуль бесплатен), четвертьволновая таблица
  синуса на 1024 записи, обратный корень с range reduction
- `bench/fx.bench.ts` — гейт P0-07

## Право

IP оригинала жив. **Можно** воспроизводить механики, системы, формулы, кривые
прогрессии — авторским правом они не охраняются. **Нельзя**: декомпиляция APK/IPA,
извлечение кода или ассетов, имена героев оригинала, топонимы, сюжет.
